# 罗盘高级 UI 组件设计文档

## 概述
已完成专业级风水罗盘 UI 组件的设计与实现，达到商业级质量标准。

## 核心功能

### 1. 双盘罗盘系统
- **地盘（正针）**：主罗盘，显示真实方位
- **纳气盘（天盘缝针）**：偏移 7.5° 的辅助罗盘，用于纳气测量
- 支持独立显示或叠加显示

### 2. 精美的视觉设计

#### 外圈装饰环
- 三层同心圆环设计
- 四正位标记（子午卯酉）
- 渐变透明度营造层次感

#### 主盘面
- 径向渐变背景
- 多层分隔线
- 磁场干扰时的波纹动画效果
- 阴影和光泽效果

#### 二十四山刻度
- 清晰的方位文字标注
- 分级刻度线（主刻度 12px，次刻度 8px）
- 五行标记（彩色圆点）
- 文字阴影增强可读性

#### 八卦标记
- 传统八卦符号
- 黄色/橙色高亮显示
- 装饰线条
- 位于内圈 115px 半径处

#### 度数标注
- 每 30° 主刻度标注
- 每 5° 细密刻度线
- 等宽字体显示数字
- 灰色低调设计

#### 中心圆盘
- 径向渐变背景
- 盘面类型标识（地盘/纳气）
- 锁定状态图标
- 红色十字准星（仅地盘）

### 3. 动画效果

#### 平滑旋转
- Spring 动画（response: 0.3, dampingFraction: 0.8）
- 自然的物理感
- 跟随设备方位实时更新

#### 锁定效果
- 锁定时停止旋转
- 红色锁定图标显示
- 保持当前方位

#### 磁场干扰动画
- 三层波纹扩散效果
- 正弦波动画
- 橙色警告色

### 4. 磁场干扰视觉提示

#### 指示器组件
- 橙色警告图标（三角形感叹号）
- 脉冲动画效果（1.0 - 1.2 缩放）
- 实时磁场强度数值显示（μT）
- 半透明背景卡片
- 阴影效果

#### 触发条件
- 磁场强度 > 100 μT 时显示
- 同时在主盘面显示波纹动画

### 5. 水平仪校准指示器

#### 气泡水平仪
- 80x40 圆角矩形外框
- 12px 圆形气泡
- 根据俯仰角和横滚角实时移动
- 中心十字准星

#### 颜色指示
- 水平（±2°）：绿色
- 倾斜（>±2°）：橙色

#### 数值显示
- 俯仰角（pitch）
- 横滚角（roll）
- 等宽字体，精确到 0.1°

#### 触发条件
- 俯仰角或横滚角 > ±5° 时显示

### 6. 深色模式支持

#### 自动适配
- 使用 `@Environment(\.colorScheme)` 检测
- 所有颜色自动切换

#### 深色模式配色
- 背景：黑色
- 主文字：白色 90% 不透明度
- 装饰环：白色
- 八卦标记：黄色
- 阴影：黑色

#### 浅色模式配色
- 背景：白色
- 主文字：黑色 80% 不透明度
- 装饰环：黑色
- 八卦标记：橙色
- 阴影：白色

### 7. 自定义主题

#### 地盘主题
- 白色/黑色主色调
- 黄色/橙色八卦标记
- 红色十字准星
- 五行彩色标记

#### 纳气盘主题
- 青色（Cyan）主色调
- 半透明效果
- 与地盘形成对比

## 技术实现

### 组件架构
```
CompassDiskView (主容器)
├── OuterRingView (外圈装饰环)
├── MainDiskView (主盘面)
├── TwentyFourMountainsView (二十四山刻度)
├── BaguaMarkersView (八卦标记)
├── DegreeMarkersView (度数标注)
├── CenterDiskView (中心圆盘)
│   └── CrosshairView (十字准星)
├── MagneticInterferenceIndicator (磁场干扰指示器)
└── LevelIndicatorView (水平仪指示器)
```

### 参数接口
```swift
CompassDiskView(
    heading: Double,                    // 方位角度
    diskType: DiskType,                 // 盘面类型
    magneticInterference: Double = 0.0, // 磁场干扰强度
    isLocked: Bool = false,             // 锁定状态
    levelOffset: (pitch: Double, roll: Double) = (0, 0) // 水平偏移
)
```

### 性能优化
- 使用 `@State` 管理动画状态
- 条件渲染减少不必要的视图
- 高效的旋转变换
- 合理的视图层级

## 使用示例

```swift
// 基础使用
CompassDiskView(
    heading: 45,
    diskType: .earth
)

// 完整功能
CompassDiskView(
    heading: viewModel.heading,
    diskType: .earth,
    magneticInterference: viewModel.magneticFieldStrength,
    isLocked: viewModel.isLocked,
    levelOffset: (pitch: viewModel.pitch, roll: viewModel.roll)
)

// 纳气盘叠加
ZStack {
    CompassDiskView(heading: heading, diskType: .earth)
    CompassDiskView(heading: heading + 7.5, diskType: .naqi)
        .opacity(0.6)
}
```
