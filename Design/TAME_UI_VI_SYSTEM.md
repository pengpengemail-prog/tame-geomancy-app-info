# TAME·Geomancy UI VI System

更新时间：2026-05-06

## 总方向

- 品牌方向：`premium utility` + `mystical precision`
- 核心气质：`克制`、`安静`、`精密`、`留白`
- 主视觉隐喻：`罗盘`、`轴心`、`细环`、`五行短弧`

## 基础规则

- 背景统一使用暖白，不做厚重深色大底。
- 主文字使用深墨黑，避免纯黑压迫感。
- 金色只做强调，不做大面积装饰。
- 细线、轻阴影、低对比辅助环优先。
- 信息卡优先“少而稳”，不要堆成说明书面板。

## 颜色角色

- 背景白：`#FDFCFB`
- 主文字：`#0D1117`
- 次级文字：主文字 68% 不透明度
- 香槟金：`#BDA06A`
- 幽灵辅助线：主文字 4% 不透明度

## 布局语言

- 页面顶部要有明显留白，不做拥挤首屏。
- 标题采用小金色编号 + 轻量标题，而不是厚重分区头。
- 卡片以单层白卡为主，圆角统一偏大，边线极细。
- 模块入口更像“目录卡”或“仪器卡”，少用花哨徽章。

## 组件语言

- 徽章：圆环 + 五行短弧 + 中心轴心
- 按钮：浅金填充或白底细边，不做重渐变
- 指标块：小字号标签 + 大数字，间距要松
- 底部导航：暖白胶囊底，图标线性、低噪音

## 禁止项

- 不要彩色功能卡
- 不要粗黑外框
- 不要大面积渐变
- 不要密集说明式图标与标签
- 不要开发面板感、仪表盘堆叠感

## 执行顺序

1. 首页与分析中心先完全对齐此规范
2. 罗盘、纳气、飞星、户型、八宅、流年按同一规则平推
3. 截图与 App Store 视觉复用同一套版式语言
